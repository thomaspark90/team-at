# 토스 결제 수수료율 자료 (공시 기반)

- **출처**: https://pay.toss.im/commission/ (토스페이 수수료율 공시)
- **조회일**: 2026-07-21
- **공시 기간**: 2025.09 ~ 2026.02 (최근 공시)
- **기준**: 공시율은 **결제액(VAT 포함 결제금액) 대비**, 수수료 자체는 **VAT 별도**
- 공시율은 "결제수단별 수취 수수료 금액 ÷ 결제액"의 **평균치**로, 실제 계약 요율과 다를 수 있음(페이지 명시). 정산서 실제 금액이 있으면 그것이 우선.

## 2. ERP 기본율(CHANNEL_FEE_RATE) 환산 산정

ERP 추정식은 `공급가액 × 기본율`이므로 공시율(결제액 기준·VAT 별도)을 공급가액 기준으로 환산해야 한다.

- 결제액 = 공급가액 × 1.1 → 환산계수 ×1.1
- 수수료 VAT(10%)는 매입세액공제 대상 → 관리손익(공급가액 기준)에서는 **비용에서 제외**하는 것이 정합적

```
공급가액 기준 요율 = 공시율 × 1.1
(수수료 VAT까지 비용으로 볼 경우 × 1.21)
```

### 산정 결과 — 가든 = 영세 구간 **확정** (2026-07-21 사용자 확인)

결제 믹스 가정: 카드 95% / 토스머니 5% (정산서로 실측 시 갱신)

| 항목 | 결제액 기준(공시) | 공급가액 기준(VAT공제 반영) | 공급가액 기준(수수료VAT 포함 시) |
|---|---|---|---|
| 카드 | 0.79% | 0.869% | 0.956% |
| 토스머니 | 1.07% | 1.177% | 1.295% |
| **블렌디드(95/5)** | **0.804%** | **0.884%** | **0.973%** |

→ **권장 CHANNEL_FEE_RATE = 0.009 (0.9%)** — VAT공제 반영 기준, 반올림.

참고(중소1, 연매출 3~5억일 경우): 블렌디드 1.18%(결제액) → 공급가액 기준 **1.30%** → 기본율 0.013.

### 현행 코드와의 차이

`lib/finance/pnl.ts`의 `CHANNEL_FEE_RATE = 0.017`(1.7%)은 공시 기반 산정치(0.9%)의 약 2배.
1.7%는 초기 근사치였으므로, **실제 정산서 1~2개월치로 검증 후 0.009로 하향** 권장.
실제 금액 입력 시 추정은 무시되므로 운영상 위험은 낮음.
