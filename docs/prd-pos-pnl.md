# PRD — 토스 POS 매출 연동 & 관리손익(발생주의) 탭

- 상태: **구현 완료 · 운영 중** (MVP 전체 + 후속이던 채널수수료까지 A+B 방식으로 구현) — 2026-07-15 현행화
- 작성: 2026-07-05
- 데이터: 토스 매출리포트 엑셀 `상품 주문 상세내역` 시트 (암호화, 비번 `0000`)
- 관련: [[정산 전 관리손익 방향(메모)]], 거래분류(지출측), docs/prd-card-statement.md

## 1. 배경 / 문제
지출측(통장·카드·영수증)은 촘촘한데 **매출측이 통장 입금(현금주의)뿐**이라 발생주의 관리손익·재료율 산출 불가. 토스 POS 매출리포트(품목단위)를 올려 **발생주의 매출**을 세우고, 매입기준 재료비와 매칭해 **관리손익 + F&B 지표(재료율·인건비율·Prime Cost)**를 만든다.

## 2. 목표 / 비목표
**목표**: POS 공급가액 매출(발생주의) 산출 → 재료비(매입+기말재고)·인건비·고정비와 매칭 → 관리손익 탭 + 지표.
**비목표(후속)**: ~~채널수수료 실효율 반영~~(구현됨: 정산서 실입력+추정 폴백), 배달앱 매출, 품목 판매분석, 토스플레이스 API 자동연동.

## 4. 데이터 모델
### 4.1 `finance.pos_sales` (신규) — 일×카테고리 집계
- `ym text`, `sale_date date`, `category text`(COFFEE/BAKERY/…), `qty numeric`, `gross bigint`(실판매금액 합, VAT포함), `vat bigint`(부가세액 합), `supply bigint`(공급가액=gross−vat)
- 상품권(금액권/선불권) 제외, 취소(음수) 반영. 재업로드 시 **해당 ym 삭제 후 재삽입**(월 단위 교체)
- (품목단위 원본은 판매분석 2차용 — MVP는 집계만)

### 4.2 `finance.inventory` (신규) — 월별 기말재고
- `ym text`, `kind text`('식자재'|'포장소모품'), `amount bigint`, `entered_by uuid`, `updated_at`
- 재료비(그달) = 기초(전월 같은 kind 기말) + 당월매입 − 기말. 첫 달 기초=0(또는 입력)

### 4.3 지출측 = 기존 `transactions`(거래분류) 재사용
- 재료비 매입: type=cogs. 식자재=원두·우유·부자재·상품매입 / 포장소모품=포장재
- 인건비: sga 중 대분류 '인건비' / 고정비: sga 나머지 / 미분류: category null 유출

## 5. 산식 (관리손익, 월별)
```
총매출(VAT포함)   = Σ gross (pos_sales, ym)
− 부가세          = Σ vat
= 공급가액 매출    = Σ supply
− 채널수수료       = 0 (후속)
= 순매출          ≈ 공급가액 매출
− 재료비(COGS)     = 기초재고 + 당월매입 − 기말재고   (식자재/포장 각각)
= 매출총이익
− 인건비
− 고정비(판관비)
− 미분류(별도)
= 영업이익(EBIT 근사)

지표(분모=공급가액매출): 식자재원가율=식자재/매출 · total재료율 · 인건비율 · Prime=(식자재+인건비)/매출
벤치마크: 재료율28~35% · 인건비25~30% · Prime≤55~60% → 초록/노랑/빨강
```

## 6. 파서 (`lib/finance/pos.ts`)
- 입력: 암호화 xlsx + 비번 → **복호화**(Node: `officecrypto-tool` 등 검증 필요, 안 되면 무암호 재저장 안내) → SheetJS로 `상품 주문 상세내역` 읽기
- 헤더 기준 컬럼 매핑(주문기준일자·결제상태·주문채널·상품명·카테고리·수량·실판매금액·과세여부·부가세액). 설명행(2행째) 스킵
- 상품권(금액권/선불권) 제외, 완료+취소(음수) 합산, (ymd,category) 집계
- 실측 검증: 6월 9,899행 → 매출총액 60,883,520 / 공급가액 55,348,360 재현

## 7. 화면 — `/finance/pnl` 관리손익 탭
- 월 선택 드롭다운
- 상단 **지표 카드**(식자재원가율·인건비율·Prime·매출총이익률) + 벤치마크 색
- **손익계산서 표**(위 산식 순서, 각 줄 금액·비율)
- **기말재고 입력**(식자재/포장소모품 월별 금액)
- 미분류 있으면 "이번 달 미분류 N건 → 분류하러" 링크 + 지표 경고 배지
- FinanceNav에 `관리손익` 추가

## 8. 엣지케이스
- 상품권으로 결제한 품목이 실판매금액=커피값으로 잡히는지 파싱 시 확인(발생주의). 상품권 category 행만 제외
- 취소가 월 넘어가면 주문기준일자 기준(토스 기록) 따름
- 기말재고 미입력 월 = 매입 그대로(경고)
- 배달 매출 없음(이 파일) → 배달앱 정산서로 후속 보완
