### 분포 형태 (차트 관찰)
- 부피 분포는 전 샷 공통 632~1414µm 집중, 주봉 773~1157µm.
- 입자 개수 곡선의 미분 봉우리(231~346µm 부근)는 **강함 3샷에서 일관되게 가장 큼**

### 인사이트 (양재천 기준선, v2)
1. **평균 크기는 배전도 영향이 작다 — 3샷 확보로 확정.** 낮음 928.8 ≈ 강함 926.7µm,
   중간만 약간 가늘게(884~899). 단조 경향이 없어 배전도보다 원두 개체 특성으로 보임.
   → 지점 간 환산 1차 산식(평균 µm 매칭)에 배전도 항 불필요.
2. **표준편차는 다크에서 일관되게 +21%** — 강함 3샷 전부 σ 247~259 vs 낮음·중간 200~214.
   배전도↑ → 취성↑ → 미분·분포폭 증가 가설이 3샷 반복으로 확인됨.
   → 환산 후 "다크 원두는 미분↑, 추출 주의" 보정 코멘트의 정량 근거.
3. **측정 반복성**: 샷 간 SD 8~15µm(중간 제외), 평균의 1~1.6%. 3샷 평균이면 산식 입력으로
   충분. 10샷 체제로 가면 ±2SD 이상치 자동 컷 적용 예정.

## 판교 수동 보정 이력 → 물 보정 상수 환류 (설계, 2026-07-17)

물 pH·미네랄 차이로 산식(입자 크기 매칭)이 맛까지 보장하지 못하므로, 필터 레시피 카드에서
판교점이 분쇄도를 직접 보정할 수 있고 이력이 남는다(`DripRecipe.pangyoMeshHistory`).
각 이력엔 **보정값(mesh) + 보정 당시 양재천 기준값(baseMesh) + 일시·기록자**가 저장된다.

환류 방법 (데이터가 쌓이면):
1. 각 보정 건에서 **Δ = mesh − 산식(baseMesh)** 계산 — baseMesh가 있으므로 산식이
   바뀌어도(잠정→확정) 소급 재계산 가능.
2. 유효 보정(자동 복귀 제외, 레시피별 최신 건 우선) **n ≥ 5건**이고 Δ의 부호·크기가
   일관되면(중앙값 기준, IQR 좁음) 그 중앙값을 **판교 물 보정 상수 W**로 채택.
3. 산식을 `판교 다이얼 = 환산(양재천 다이얼) + W`로 갱신 — 입자 물리(그라인더 개체차)와
   추출 화학(물 성질)을 분리된 항으로 유지. 수동 보정 기능은 그대로 두되, W 반영 후
   Δ가 0 근처로 수렴하는지로 상수의 타당성을 검증.
4. Δ가 원두 배전도·브루 타입(ICE/HOT)별로 갈리면 상수를 조건부로 분리 검토.

## 지점 비교 판정 (2026-07-16)
1. **판교 EK43은 같은 다이얼에서 약 19~20% 가늘게 갈린다** (평균 -187µm). 세 배전도
   모두 t>4.6으로 확정적. 제로포인트/버 간격 차이로 해석.
2. 다이얼 오프셋 환산은 기울기(µm per 다이얼) 필요 — EK43 통상 90~120µm/다이얼 가정
   시 **+1.6~+2.1 다이얼** (양재천 6.5 ≈ 판교 8.1~8.6 추정). 판교 8.0 실측으로 확정할 것.
3. 판교의 상대 분포폭(CV)이 전 배전도에서 더 넓음(27~31% vs 22~27%) — 더 가늘게
   갈리니 미분 비중이 늘어난 것과 정합. 미분 개수 봉우리도 판교가 전반적으로 큼.
4. **주의**: 양재천에서 관찰된 "다크 σ 증가" 패턴이 판교에서는 재현 안 됨(판교 강함
   σ 207~211로 오히려 최저, 중간이 222~230 최고). 배전도-미분 상호작용은 장비 의존일
   수 있어 v1 산식에선 보류, 데이터 축적 후 재검토.
5. 판교는 샷 간 산포도 큼(낮음 SD 62.7 — 샷1 이상치 영향). 낮음 샷1 제외 시 낮음
   오프셋 -133.5µm. 10샷 체제 도입 시 판교부터 적용 권장.
